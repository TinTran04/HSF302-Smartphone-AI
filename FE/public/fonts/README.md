# Fonts

Inter and Material Symbols Outlined are downloaded from Google Fonts and served locally for the exported interface, including Vietnamese character subsets. The CSS at `fonts.css` records the font-family declarations.

Upstream projects: https://github.com/rsms/inter and https://github.com/google/material-design-icons.

Image assets in `public/images` are copied from the URLs embedded in the user's Stitch export. Their original sources are recorded in `scripts/stitch-assets.json`; asset usage rights remain those of the supplied export.
